# College Event Registration System (Circular Queue)

## 📌 Description

This project implements a college event registration system using circular queue in C.

## ⚙️ Features

* Register student (enqueue)
* Cancel registration (dequeue)
* Display list of students

## 🧠 Data Structure

Circular Queue (FIFO)

## 💻 Language

C Programming
